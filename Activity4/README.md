Hotel Guest Information

Guide Questions

10. Which variables use whole-number data types?

- In this program, roomNo and nights use the int data type. These values are counted using whole numbers, so storing decimal values for them would not make sense in this activity.

11. Why is the room rate stored as double?
- I stored the room rate as a double because hotel rates may include decimal amounts. This allows the program to accept values such as 1800.50 instead of limiting the input to whole numbers only.

12. What comment could you add to explain the purpose of the Scanner object?

- The comment I would add is // This Scanner lets the user enter the hotel guest's details. It explains its purpose directly without making the comment too long.
