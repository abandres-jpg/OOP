Mobile Phone Record

Guide Questions

13. Why should RAM and storage be ints in this problem?

- Since the RAM and storage capacities given in this activity are whole numbers, I would store them as int. Values such as 8 GB and 256 GB do not need a decimal part in this program.

14. How do comments help another programmer understand the code?

- For me, comments make the code easier to follow because they give a short explanation of what a certain part is meant to do. This is helpful when another programmer reads the code for the first time.

15. What is the purpose of System.out.println()?

- In this program, System.out.println() is used to display the phone information one line at a time. After printing a value, it automatically moves the next output to a new line.
